Boolean algebra & logic gates

A computer only knows two values: 1 and 0. Logic gates are tiny circuits that combine these values. Boolean algebra is the maths for writing and simplifying those combinations, so we can build smaller, faster circuits.

Think of it like this: a lamp wired through two switches. If the switches are in a row (series), the lamp lights only when switch A and switch B are on. If they sit side by side (parallel), it lights when A or B is on. That is AND and OR.

Key terms

Boolean variable
A name (A, B, …) that can only be 0 or 1.
Logic level
1 = TRUE = HIGH = ON (about 3.3 V or 5 V). 0 = FALSE = LOW (about 0 V).
Logic gate
A small circuit with one or more inputs and one output, following a fixed rule.
Truth table
A table listing the output for every possible input. With n inputs there are 2n rows.
Complement (A')
The opposite of A. Also written A, ¬A or ~A.
Bubble
The small circle on a gate symbol. It means "invert (NOT) here".
ISA
Instruction Set Architecture: the list of commands a CPU understands (e.g. ADD). The contract between software and hardware.
Universal gate
A gate type that can build every other gate on its own. NAND and NOR are universal.

1. Where gates fit: architecture, organisation and abstraction

Architecture = the "what"

What the programmer can see and use. Example: "this CPU has an ADD instruction".

Organisation = the "how"

How the hardware delivers it, hidden from the programmer: pipelines, caches, clock speed.

Two CPUs can share the same architecture (run the same programs) but have different organisations (one is faster). Computers are built in layers. Each layer hides the details of the layer below it. This is called abstraction.

Universal gates

NAND alone can build every other gate. So can NOR alone. For example, tie both NAND inputs together: NOT A = A NAND A, because (A·A)' = A'. Full constructions are on Logic minimization.

4. Boolean laws

These rules let you shrink an expression without changing its truth table. Each law has two forms: swap + with · and 0 with 1 to get the other one (this pairing is called duality).

Why A + A·B = A

If A = 1, both sides are 1. If A = 0, then A·B = 0, so both sides are 0. B never matters.

5. De Morgan's theorems

(A · B)' = A' + B'"Not both" = "at least one is not". A NAND is an OR with inverted inputs.
(A + B)' = A' · B'"Neither" = "not A and not B". A NOR is an AND with inverted inputs.
Instructor's rule: "Break the bar, flip the sign"

Cut the long bar over the group into short bars over each variable, and change · to + (or + to ·). It works for any number of variables: (ABC)' = A' + B' + C'.

Proof by truth table

The two copper-edged columns match in every row, so the two expressions are equal. A truth table is the final judge: trust it over intuition.

6. Worked simplification

Simplify Y = A·B + A·B'.

  1. Factor out A (distributive law): Y = A·(B + B')
  2. Complement law: B + B' = 1, so Y = A·1
  3. Identity law: A·1 = A, so Y = A
  4. Result: two ANDs, one OR and one NOT become a single wire. Whatever B does, Y just copies A.

Another: A + A'B = A + B

  1. Distributive (OR form): A + A'B = (A + A')(A + B)
  2. Complement: A + A' = 1, so = 1·(A + B)
  3. Identity: = A + B

Common mistakes & exam traps

Slips that cost marks
  • Reading + as addition. A + 1 = 1, not 2.
  • Mixing up OR and XOR. Check the 1,1 row: OR gives 1, XOR gives 0.
  • Treating NAND as AND. The bubble flips every output.
  • Applying De Morgan halfway: (AB)' is not A'B'. Flip the sign too: A' + B'.
  • Forgetting the OR form of the distributive law: A + BC = (A+B)(A+C).
  • Confusing architecture (what the programmer sees) with organisation (how it is built).
  • Trusting a "feels right" simplification. Check it with a truth table.

Practice

What is XOR(1, 1)? What is OR(1, 1)?

XOR(1,1) = 0 (inputs are the same). OR(1,1) = 1.

Where does the ISA sit in the abstraction stack?

Between the operating system (above) and the datapath & control (below). It is the boundary between software and hardware.

Simplify A·(A + B).

Expand: A·A + A·B = A + AB (idempotent). Then absorption: A + AB = A. Answer: A.

Apply De Morgan to (ABC)'.

Break the bar, flip the sign: A' + B' + C'.

Show that XY + X'Z + YZ = XY + X'Z.

YZ = YZ·(X + X') = XYZ + X'YZ

So the whole thing is XY + XYZ + X'Z + X'YZ. By absorption, XY + XYZ = XY and X'Z + X'YZ = X'Z.

Result: XY + X'Z. The YZ term (called the consensus term) was redundant.

Simplify (A + B)(A' + C).

Multiply out: AA' + AC + A'B + BC. AA' = 0, so AC + A'B + BC.

BC is the consensus of AC and A'B, so it drops out: AC + A'B.

Simplify ((A'+B)' + (AC)')'.

De Morgan on the outer bar: (A'+B)'' · (AC)'' = (A' + B)·AC.

Expand: A'AC + ABC = 0 + ABC. Answer: ABC.

Show that ((A+B)'·C)' + (AB)' = 1.

De Morgan on each part: ((A+B)'·C)' = (A+B) + C' and (AB)' = A' + B'.

Together: A + B + C' + A' + B'. It contains A + A' = 1, and anything OR 1 is 1. Answer: 1.
