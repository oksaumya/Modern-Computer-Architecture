Number systems & two's complement

Computers store everything as bits (0s and 1s). This page covers how to write numbers in binary and hexadecimal, and how to store negative numbers using two's complement. Two's complement is the system every modern CPU uses, because one adder circuit can then do both addition and subtraction.

Think of it like this: a car's odometer with 4 digits. Roll it back one step from 0000 and it shows 9999. Two's complement uses the same idea: step back one from 0000 and you get 1111, and we agree that this pattern means −1.

Key terms

Bit / nibble / byte
A bit is one binary digit (0 or 1). A nibble is 4 bits. A byte is 8 bits.
Base (radix)
How many different digits a number system uses. Decimal is base 10, binary is base 2, and hexadecimal is base 16.
MSB / LSB
The most significant bit is the leftmost bit, with the biggest weight. The least significant bit is the rightmost bit, with weight 1.
Unsigned
Every bit pattern means zero or a positive number. 4 bits give 0 to 15.
Signed
Patterns can mean negative numbers too. In two's complement, 4 bits give −8 to +7.
Sign bit
The MSB of a signed number. 0 means zero or positive; 1 means negative.
Hexadecimal (hex)
Base 16, with digits 0–9 and A–F. It is written with a 0x prefix, as in 0x2A.
Overflow
The true answer does not fit in the available bits. It happens silently, with no error message.
One pattern, two meanings

11111111 is 255 if you read it as unsigned, and −1 if you read it as signed. The bits are identical. "The CPU only knows which you meant by which instruction you use."

1. Positional notation

In any base, each position is worth the base raised to a power. Start at the right with power 0. Multiply each digit by its position's weight, then add everything up.

2. Decimal → binary: divide by 2

Divide by 2 again and again, writing down each remainder (0 or 1). Stop when you reach 0. Then read the remainders from bottom to top. The first remainder is the LSB.

Worked example: 42 to binary

42 ÷ 2 = 21, remainder 0. This is the LSB (bit 0).

21 ÷ 2 = 10, remainder 1 (bit 1).

10 ÷ 2 = 5, remainder 0 (bit 2).

5 ÷ 2 = 2, remainder 1 (bit 3).

2 ÷ 2 = 1, remainder 0 (bit 4).

1 ÷ 2 = 0, remainder 1 (bit 5, the MSB). The quotient is 0, so stop.

Read bottom to top: 1 0 1 0 1 0, so 42 = 101010. Check: 32 + 8 + 2 = 42 ✓

Faster way for small numbers

Subtract the biggest power of 2 that fits, and repeat. For 42: 42 − 32 = 10, then 10 − 8 = 2, then 2 − 2 = 0. So you need bits 32, 8 and 2, which gives 101010.

5. Three ways to store negative numbers

Sign-magnitude

Use the MSB as a sign (0 = +, 1 = −) and the remaining bits as the size. +18 = 00010010, −18 = 10010010. It is simple, but it has two zeros (+0 and −0), and addition needs extra logic to compare signs. Today it is only used for the sign bit of floating-point numbers.

One's complement

To negate, invert every bit. +18 = 00010010, so −18 = 11101101. It still has two zeros (00000000 and 11111111), and addition needs an end-around carry: any carry out of the MSB must be added back in at the LSB.

Two's complement (the one CPUs use)

To negate, invert every bit, then add 1.

  1. Start+18 = 00010010
  2. Invert11101101
  3. Add 111101110 = −18

This works in both directions: negate 11101110 and you get 00010001 + 1 = 00010010 = +18 again. There is only one zero, and the same adder does both addition and subtraction.

Shortcut for negating in two's complement

Starting from the right, copy every bit up to and including the first 1, then invert all the bits to its left. Example: +18 = 00010010. Copy "10" and invert the rest (000100 → 111011), which gives 11101110 = −18 ✓.

6. Reading a two's complement number: the MSB weight is negative

The fastest way to read a signed pattern: treat the MSB's weight as negative. In 8 bits the MSB is worth −128 instead of +128. In 4 bits it is worth −8.

weight−1286432168421
1110111011101110
11101110 = −128 + 64 + 32 + 8 + 4 + 2 = −18The MSB gives a big negative weight, and the other bits add positive amounts back.

Another check: an unsigned value minus 2ⁿ gives the signed value whenever the MSB is 1. 11101110 unsigned is 238, and 238 − 256 = −18 ✓.

7. The number wheel (4-bit two's complement)

Put all 16 patterns on a circle. Adding 1 moves one step clockwise, and subtracting 1 moves one step anticlockwise. Past the end, the numbers wrap around, just like the odometer.

The range is not symmetric

There is one more negative number than positive: −128 has no +128 twin in 8 bits. If you negate 10000000 (−128), you get invert → 01111111, then +1 → 10000000. That is −128 again! Also, 10000000 means −128, not −0.

9. Sign extension (making a number wider)

To copy a 4-bit signed number into 8 bits, fill the new bits with copies of the sign bit. This keeps the value the same.

10. Binary addition and subtraction

There are only four facts: 0+0 = 0, 0+1 = 1, 1+1 = 10 (write 0, carry 1), and 1+1+1 = 11 (write 1, carry 1).

Addition: 1101 + 1011 (13 + 11)

  carry 1 1 1 1
          1 1 0 1     (13)
        + 1 0 1 1     (11)
        ---------
        1 1 0 0 0     (24)
  1. Bit 0: 1 + 1 = 10. Write 0, carry 1.
  2. Bit 1: 0 + 1 + 1 = 10. Write 0, carry 1.
  3. Bit 2: 1 + 0 + 1 = 10. Write 0, carry 1.
  4. Bit 3: 1 + 1 + 1 = 11. Write 1, carry 1.
  5. Result: 1 1000 = 24 ✓. The answer needs 5 bits. In a 4-bit register only 1000 is kept, and the carry-out of 1 shows the answer overflowed 4 unsigned bits.

Subtraction: add the negative

A − B = A + (~B + 1)~B means "invert every bit of B". Throw away any carry out of the MSB.

5 − 3

−3 = invert 0011 → 1100, then +1 → 1101.

0101 + 1101 = 1 0010. Drop the carry to get 0010 = +2 ✓

3 − 5

−5 = invert 0101 → 1010, then +1 → 1011.

0011 + 1011 = 1110 (no carry out). Read it: −8 + 4 + 2 = −2 ✓

Why this is so useful

The CPU does not need a separate subtractor. It inverts B and feeds 1 into the adder's carry-in. See the adder-subtractor for the circuit.

Common mistakes & exam traps

Slips that cost marks
  • Zero-padding a negative number. −5 = 1011 must become 11111011, not 00001011 (+11).
  • Forgetting the +1. Inverting alone gives one's complement, not two's complement.
  • Reading 10000000 as −0. In two's complement it is −128.
  • Assuming the range is symmetric. 8 bits give −128 … +127.
  • Reading remainders top to bottom. In the divide-by-2 method, the first remainder is the LSB.
  • Grouping hex digits from the left. Always group from the right, padding the left with 0s: 101101 → 0010 1101 = 0x2D.
  • Thinking overflow raises an error. It is SILENT. The hardware just keeps the low bits.

Practice

Convert 0xB7 to binary. What is it as an unsigned number? As a signed (two's complement) number?

B = 1011 and 7 = 0111, so 0xB7 = 1011 0111.

Unsigned: 128+32+16+4+2+1 = 183.
Signed: −128+32+16+4+2+1 = −73 (or 183 − 256 = −73).

Write −45 in 8-bit two's complement.

45 = 00101101 → invert: 11010010 → +1: 11010011.

Check: −128 + 64 + 16 + 2 + 1 = −45 ✓

4-bit: 0110 + 1100. What is the result, the carry-out, and is there signed overflow?

6 + (−4) = 2. 0110 + 1100 = 1 0010, so the 4-bit result is 0010 = 2 and the carry-out is 1.

No signed overflow: the two inputs have different signs, and adding a positive to a negative can never overflow. The carry-out is irrelevant for signed numbers.

What is 0xFF as a signed 8-bit number?

11111111 = −128 + 127 = −1. (Unsigned, it is 255.)

Convert 100 to binary and to hex.

100 − 64 = 36, 36 − 32 = 4, 4 − 4 = 0. So bits 64, 32 and 4 are set: 01100100.

Group as 0110 0100 = 0x64. Check: 6×16 + 4 = 100 ✓

Add 25 + (−10) in 8-bit two's complement.

25 = 00011001. 10 = 00001010 → invert 11110101 → +1 11110110 = −10.

00011001 + 11110110 = 1 00001111. Drop the carry to get 00001111 = 15 ✓

Sign-extend the 4-bit value 1001 to 8 bits. What value is it?

The sign bit is 1, so fill with 1s: 11111001.

4-bit: −8 + 1 = −7. 8-bit: −128+64+32+16+8+1 = −7 ✓. The value is unchanged.

What is the range of a 16-bit signed integer? Why is it not symmetric?

−32,768 … +32,767. There are 65,536 patterns. One of them is zero, and zero uses a pattern with sign bit 0, so the positive side gets one fewer value than the negative side.
