Latches: how a circuit remembers one bit

Everything in Module 1 had no memory. A CPU must remember things: the program counter, register values, what step it is on. A latch is the simplest circuit that stores one bit. It does this with a feedback loop: its output is wired back into its own input.

Think of it like this: a light switch. Press "on" and the light stays on after you let go. Press "off" and it stays off. The switch remembers the last button you pressed. An adder can't do that: take away its inputs and its answer is gone.

Key terms

Combinational circuit
Output depends only on the inputs right now. No memory. Adders, MUXes, decoders.
Sequential circuit
Output depends on the inputs and on what happened before (its stored state).
State
The value a circuit is currently storing. For a latch, that is its output Q.
Feedback
Wiring a gate's output back to an earlier gate's input, so the circuit keeps "seeing" its own value.
Q and Q'
Q is the stored bit. Q' ("Q bar", also written Q̄) should always be its opposite.
Set / Reset
Set means make Q = 1. Reset (also called clear) means make Q = 0.
Enable (E)
A control input. When E = 1 the latch listens to its data inputs. When E = 0 it ignores them.
Transparent
The output simply follows the input, as if the latch were a plain wire.

1. Combinational vs sequential

Try building a counter with only AND, OR and XOR gates. You can't. A counter must know the last number to produce the next one, and those gates forget everything. The difference comes down to one thing: a feedback loop.

2. The bistable element: memory with no controls

Connect two NOT gates (inverters) in a loop. If Q = 1, the first inverter makes Q' = 0, and the second turns that 0 back into Q = 1. The loop keeps itself going. It has exactly two stable states (Q = 1 or Q = 0), so it is called bistable. It holds its bit as long as it has power.

The problem: there is no way to change the stored bit. It is sealed. A latch replaces the inverters with gates that have extra inputs, so we can control it.

3. The SR latch (built from NOR gates)

Swap each inverter for a NOR gate (OR followed by NOT: output is 1 only when all inputs are 0). Each NOR gets one extra input: S (set) and R (reset). The two gates are cross-coupled: each gate's output feeds the other gate's input.

Q = (R + Q')'   ·   Q' = (S + Q)'+ means OR, and the ' after a bracket means NOT. In Verilog: q = ~(r | qbar), qbar = ~(s | q).

Why S = R = 1 is forbidden (click through)

Step 1: S = 1, R = 1. A NOR with any input at 1 outputs 0. So the top gate gives Q = 0 and the bottom gate gives Q' = 0.

Step 2: the rule is broken. Q and Q' are both 0. Q' is supposed to be the opposite of Q, so the latch is in a meaningless state.

Step 3: now S and R both drop to 0 at the same moment. Each gate now sees two 0s, so each tries to output 1. Both outputs start rising together.

Step 4: a race. Whichever gate is a tiny bit faster reaches 1 first and forces the other back to 0. That depends on picosecond differences in gate delay, so the result is unpredictable (non-deterministic). It may even oscillate for a while.

Lesson: never apply S = R = 1. The D latch below makes this combination impossible.

The NAND version

You can also build an SR latch from two cross-coupled NAND gates. NAND gates are cheap, so this version is common in practice. Its inputs are active-LOW: a 0 does the action. We write them S' and R'.

Same idea, flipped. NOR latch: 1 acts, forbidden is 11. NAND latch: 0 acts, forbidden is 00 (both outputs become 1).

Active-LOW just means "the input does its job when it is 0".

Why a plain SR latch is hard to use

  1. Two control lines is one too many. You must keep S and R from both being 1.
  2. Any glitch gets through. A 1 ns spike on S sets the latch by accident.
  3. It has no notion of "now". It reacts whenever its inputs change.

The D latch fixes problems 1 and 2. The flip-flop fixes problem 3.

4. The gated SR latch

Add an enable input E. Put an AND gate in front of S and in front of R, both also fed by E.

  • E = 1: S and R pass through. The latch responds normally.
  • E = 0: both AND gates output 0, so the latch sees S = R = 0 and holds.

Now we can choose when the latch listens. But S = R = 1 is still possible while E = 1.

5. The D latch

Give the latch just one data input, D. Inside, make S = D·E and R = D'·E. Since D and D' are always opposite, S and R can never both be 1. The forbidden state is now impossible.

Where are latches still used?

Inside SRAM memory cells (see SRAM vs DRAM), for "time borrowing" between pipeline stages, and in asynchronous reset circuits. Most other storage in a CPU uses flip-flops.

Common mistakes & exam traps

Slips that cost marks
  • Saying S = R = 1 "sets and resets". It is forbidden: Q = Q' = 0, then a race.
  • Mixing up NOR and NAND latches. NOR: active-high, forbidden 11. NAND: active-low, forbidden 00.
  • Forgetting that a D latch is transparent the whole time E = 1. Every glitch on D reaches Q.
  • Calling a latch a flip-flop. A latch reacts to a level; a flip-flop reacts to an edge.
  • Q showing X at the start of simulation is normal: nothing has been stored yet.
  • iverilog "unknown module sr_latch"? Pass sr_latch.v on the command line too.

Practice

What single feature turns a combinational circuit into a sequential one?

A feedback loop: an output wired back to an input, so the circuit can hold a value.

A NOR SR latch has Q = 1. Apply S = 0, R = 0. What is Q? Then apply S = 0, R = 1. What is Q?

S = R = 0 is hold, so Q stays 1. S = 0, R = 1 is reset, so Q = 0.

Why is S = R = 1 forbidden in a NOR latch? Give two reasons.

1) Both outputs become 0, so Q' is no longer the opposite of Q. 2) If S and R then fall together, both gates race to 1 and the final state depends on tiny delay differences, so it is unpredictable.

In a NAND SR latch, which input combination is forbidden, and what do the outputs show?

S' = R' = 0. Both outputs become 1.

Show why a D latch can never reach the forbidden state.

S = D·E and R = D'·E. For both to be 1 we would need D = 1 and D' = 1 at the same time, which is impossible. So S·R = D·D'·E = 0 always.

A D latch has E = 1 while D goes 0 → 1 → 0. Then E falls. Then D goes to 1. What is Q at the end?

While E = 1, Q follows D: 0 → 1 → 0. When E falls, D is 0, so Q holds 0. The later change of D is ignored. Q = 0.

List the three problems of a plain SR latch and which later circuit fixes each.

Two control lines (fixed by the D latch), glitches get through (D latch with enable), no notion of "now" (fixed by the edge-triggered flip-flop).
