Registers & shift registers

A register is a row of D flip-flops that share one clock, so a whole word (8, 32 or 64 bits) is stored at once. A shift register is a register whose bits move one place along on every clock edge.

Think of it like this: a register is a row of lockers that all open and shut at the same bell. A shift register is a conveyor belt: at every bell, each box moves one spot along, a new box goes on at one end and the last box falls off the other.

Key terms

Register
n D flip-flops with a shared clock, storing an n-bit word.
Load (LD) / load enable
A control input. 1 = store new data at the edge. 0 = keep the old value.
Clear / reset
A control input that sets every bit to 0.
Serial
One bit at a time on one wire, one bit per clock edge.
Parallel
All n bits at once on n wires, in a single edge.
MUX (multiplexer)
A selector switch: a control input picks which of its data inputs reaches the output.
Concatenation { }
Verilog for gluing bits together: {2'b10, 1'b1} = 101.
Bit slice q[2:0]
Bits 2, 1 and 0 of q, as a 3-bit group.

1. Registers

Are registers made of flip-flops? Yes, always. A CPU register is 32 or 64 D flip-flops. The program counter (PC), the instruction register and the pipeline registers are all registers.

Load enable: a MUX in front of every D

A plain D flip-flop stores D on every edge. To keep a value when we don't want to change it, put a 2:1 MUX in front of each D input:

  • LOAD = 1: the MUX passes the new data.
  • LOAD = 0: the MUX passes the flip-flop's own Q back in, so it stores the same value again (hold).

In Verilog you don't draw the MUX. Writing if (ld) q <= d; with no else means "otherwise keep q", and the tool builds the MUX for you.

Serial vs parallel

Serial

1 wire. One bit moves per clock edge, so n bits take n edges. Cheap wiring. (USB, UART, SPI)

Parallel

n wires. All n bits move on one edge. Fast, but needs many wires. (inside a CPU)

3. Shift registers

Connect each flip-flop's Q to the next one's D. On every edge, every bit moves one place: a conveyor belt for bits.

ModeInOutTypical use
SISOserialserialdelay line (output = input from n edges ago)
SIPOserialparallelUART receive (bits arrive one by one, CPU reads a byte)
PISOparallelserialUART transmit (CPU gives a byte, it leaves bit by bit)
PIPOparallelparallelbuffer register with load (the Lab Q1 register)

Other uses: serial ↔ parallel conversion (UART, SPI, USB); an N-cycle delay; shift left = ×2 and shift right = ÷2; LFSRs (a shift register with XOR feedback) that make pseudo-random numbers.

PISO: worked example (load 1011, then shift right)

Each D input needs a 2:1 MUX: one input for "load", one for "shift". The output sout is always q[0], so the LSB leaves first.

EdgeActionq[3:0] aftersout = q[0]
1load10111
2shift01011
3shift00100
4shift00011
5shift00000

sout sends out 1, 1, 0, 1: the bits of 1011 read from right to left (LSB first).

verilog · PISO (class version)code → what it means
always @(posedge clk) begin
if (load) q <= d; // parallel loadload = 1: take all 4 bits at once.
else q <= {1'b0, q[3:1]}; // shift rightload = 0: put a 0 on the left, drop q[0]. Everything moves right.
end
assign sout = q[0];The serial output is the rightmost bit.

Slide correction: which value loads?

The lab question says load = 1 captures d and load = 0 shifts. The posted solution does the opposite: it loads when sh_ld = 0 (an active-low load) and shifts when sh_ld = 1. Both designs work; they just use opposite control values.

To match the question exactly, change the load test to else if (load) q <= d; (and rename the input load). With the posted code, your testbench must drive sh_ld = 0 to load and sh_ld = 1 to shift. Always state which convention you used in an exam answer.

PIPO

Parallel in, parallel out: exactly the Lab Q1 register with load. All bits go in on one edge and are all readable at once.

4. Bidirectional & universal shift registers

  • Bidirectional: adds a direction input, so it can shift left or right.
  • Universal: adds a 2-bit mode select that chooses one of four actions: hold, shift left, shift right, parallel load. Each flip-flop gets a 4:1 MUX in front of it (a bigger version of the load MUX above).

Common mistakes & exam traps

Slips that cost marks
  • Using = instead of <= in a shift. With =, the line order matters and bits can be overwritten before they move.
  • Forgetting that if (ld) with no else means hold, not "clear".
  • Putting the load test before the reset test: reset must have top priority.
  • Mixing up shift direction: {q[2:0], x} shifts left; {x, q[3:1]} shifts right.
  • Getting the PISO output order wrong: with sout = q[0] and right shifts, the LSB goes first.
  • Driving the wrong sh_ld value in the Lab Q4 testbench (0 loads in the posted code).

Practice

A 4-bit register with load holds 1010. ld = 0 and d = 0110. What is q after the edge?

ld = 0 means hold: q = 1010.

In Lab Q2, rst = 1 and ld = 1 at the same edge. What happens?

rst is checked first, so q = 00000000. The load is ignored.

A SIPO register (q <= {q[2:0], sin}) starts at 0000. Shift in 1, 1, 0, 1. Show q after each edge.

0001 → 0011 → 0110 → 1101.

A PISO loads 0110, then shifts right 4 times. What bits come out on sout = q[0]?

q: 0110 → 0011 → 0001 → 0000. sout reads q[0] before each shift: 0, 1, 1, 0 (LSB first).

How many clock edges does a 4-bit SISO need before the first input bit appears at serial_out?

4 edges: the bit must pass through q[0], q[1], q[2] and q[3].

Why does shifting left multiply by 2?

Every bit moves to a place worth twice as much, and a 0 enters at the right. Example: 0011 (3) → 0110 (6). (Bits shifted out of the top are lost.)

Name the four actions of a universal shift register.

Hold, shift left, shift right, parallel load, chosen by a 2-bit mode select.
