Counters: ripple, synchronous, ring & Johnson

A counter is a register that steps through a fixed sequence of values, one step per clock edge. An n-bit binary counter goes 0, 1, 2 … 2ⁿ−1 and then wraps back to 0. The CPU's program counter (PC) is a counter.

Think of it like this: a car's odometer. The right wheel turns every kilometre. A wheel moves on only when every wheel to its right has just rolled over from 9 to 0. In binary the rule is the same, but each wheel only has 0 and 1.

Key terms

Counter
Register + incrementer (+1 logic) + feedback of the result into the register.
Modulus (mod-N)
The number of different states before the counter repeats. A 3-bit binary counter is mod-8.
Ripple (asynchronous) counter
Each flip-flop is clocked by the previous flip-flop's output.
Synchronous counter
All flip-flops share one clock; logic decides which ones change.
t_pd
Propagation delay: how long one flip-flop takes to update its output.
Excitation table
Tells you which flip-flop input produces a wanted change Q → Q⁺.
One-hot
Exactly one bit is 1 at a time, e.g. 0100.
⌈x⌉ (ceiling)
Round x up to the next whole number. ⌈3.58⌉ = 4.

1. The counting rule

Look at binary counting: 000, 001, 010, 011, 100… Bit 0 flips every time. Bit 1 flips when bit 0 was 1. Bit 2 flips when bits 0 and 1 were both 1.

A bit flips exactly when every bit below it is 1So, using T flip-flops (T = 1 means flip): T0 = 1 · T1 = Q0 · T2 = Q0·Q1 · T3 = Q0·Q1·Q2

2. Ripple (asynchronous) counter

Every flip-flop is a T flip-flop with T = 1, so each one flips whenever it is clocked. Only FF0 sees the real clock. Each later flip-flop is clocked by the output of the one before it, and flips when that output falls from 1 to 0 (the bubble on the clock pin means "falling edge").

  • 2-bit sequence: 00, 01, 10, 11, 00… Q1 toggles only when Q0 falls 1→0.
  • n stages count mod 2ⁿ and divide the clock frequency by 2ⁿ.

The speed limit: watch 7 → 8

Each stage waits for the one before it, so the bits change one after another. For a moment the counter shows wrong values (glitches):

3. Synchronous counter

All flip-flops share one clock. Combinational logic (the T equations) works out in advance which flip-flops should flip. At the edge they all change together, so the count is valid right after the edge, with no glitches.

Design method

  1. 1. SequenceWrite the count order.
  2. 2. State tablePresent state → next state.
  3. 3. ExcitationFind each flip-flop's input.
  4. 4. SimplifyUse K-maps.
  5. 5. WireShared clock.

T flip-flop excitation table

Q → Q⁺T
0 → 00
0 → 11
1 → 01
1 → 10

How to read it: "if the bit must change, T = 1; if it stays, T = 0".

It is the characteristic table read backwards: we know the change we want and ask which input causes it.

Worked example: 2-bit up counter

Step 1: sequence. 00 → 01 → 10 → 11 → 00 (repeat).

Step 2 & 3: state table + excitation. For each bit, compare now and next: changed → T = 1.

Step 4: simplify. T0 is 1 in every row, so T0 = 1. T1 is 1 exactly when Q0 = 1, so T1 = Q0.

Step 5: wire it. Both flip-flops on the same clock; FF0's T tied to 1; FF1's T connected to Q0. Done.

Mod-N counters

A mod-N counter has N states: 0 … N−1. Example: mod-6 from a 3-bit counter gives 0 → 1 → 2 → 3 → 4 → 5 → 0.

verilog · mod6.v (synchronous)code → what it means
module mod6 (input clk, rst,
output reg [2:0] q);3 bits are enough for 6 states (⌈log₂6⌉ = 3).
always @(posedge clk)
if (rst || q == 3'd5)|| = OR, == = "is equal to", 3'd5 = the number 5 in 3 bits. If reset, or we are at the last state…
q <= 3'd0;…go back to 0 (a synchronous reset used as the wrap).
else
q <= q + 3'd1;Otherwise count up.
endmodule
"Detect 6" or "detect 5"?

The class describes mod-6 as "detect 6 and reset". That is the asynchronous-clear version: the counter reaches 110 and is cleared immediately, so 6 appears only as a brief glitch. In a synchronous design (above), you detect the last valid state, 5, and load 0 at the next edge. Both give the sequence 0–5.

  • Output bits as clock dividers: bit 0 = clock ÷ 2, bit 1 = ÷ 4, bit 2 = ÷ 8.
  • Watch seconds: a mod-60 counter.
flip-flops needed = ⌈log₂ N⌉mod-12: log₂12 ≈ 3.58 → 4 flip-flops · dividing 1 MHz to 1 kHz needs mod-1000: log₂1000 ≈ 9.97 → 10 flip-flops

5. Ring and Johnson counters

Both are shift registers whose last output is fed back to the first input.

Ring counter

Preset a single 1, and it circulates. n flip-flops give n states, each one-hot, so no decoding is needed. Used for LED chasers and one-hot FSMs.

Both tables use the left-shift convention of the code below ({q[2:0], feedback}). The class slide draws the ring as 1000 → 0100 → 0010 → 0001, which is the same idea shifting the other way.

verilog · ring & Johnsoncode → what it means
// 4-bit ring counter
always @(posedge clk)Every rising edge…
if (rst) q <= 4'b0001;Reset must load a single 1. (All zeros would stay zero forever.)
else q <= {q[2:0], q[3]};Shift left; the bit falling off the top (q[3]) re-enters at the bottom.
// 4-bit Johnson counter
always @(posedge clk)
if (rst) q <= 4'b0000;Johnson starts from all zeros.
else q <= {q[2:0], ~q[3]};Same shift, but the re-entering bit is inverted (~ = NOT). That doubles the number of states.

Common mistakes & exam traps

Slips that cost marks
  • Using a ripple counter at high speed: its settle time is n × t_pd and it shows false values on the way.
  • Wrong number of state bits: use ⌈log₂N⌉ (mod-12 needs 4, not 3).
  • Forgetting the reset state: the counter can power up anywhere.
  • Resetting a down counter to 0 instead of MAX.
  • Resetting a ring counter to 0000: it then never leaves 0000.
  • Mixing up states: ring = n, Johnson = 2n, binary = 2ⁿ.
  • Writing T1 = 1 for a 2-bit counter: bit 1 only flips when Q0 = 1.

Practice

Write T0 … T3 for a 4-bit synchronous up counter.

T0 = 1, T1 = Q0, T2 = Q0·Q1, T3 = Q0·Q1·Q2. A bit flips when all lower bits are 1.

A 4-bit ripple counter goes from 0011 to 0100. List the values it passes through (one per t_pd).

0011 → Q0 flips → 0010 → Q1 flips → 0000 → Q2 flips → 0100. Q2 went 0→1 (not a fall), so Q3 does not flip. 3 t_pd in total, with two false values (2 and 0).

t_pd = 5 ns. What is f_max of an 8-bit ripple counter?

t_settle = 8 × 5 = 40 ns. f_max = 1 / 40 ns = 25 MHz.

How many flip-flops for a mod-60 counter? For mod-10?

log₂60 ≈ 5.91 → 6. log₂10 ≈ 3.32 → 4.

How many states do a 5-bit ring counter and a 5-bit Johnson counter have?

Ring: 5. Johnson: 2 × 5 = 10.

A 3-bit Johnson counter (q <= {q[1:0], ~q[2]}) starts at 000. List its sequence.

000 → 001 → 011 → 111 → 110 → 100 → 000. That is 6 states = 2 × 3 ✓

Using the T excitation table, find T2 T1 T0 for the step 101 → 110.

Q2: 1→1 so T2 = 0. Q1: 0→1 so T1 = 1. Q0: 1→0 so T0 = 1. T = 011. Check: T2 = Q1·Q0 = 0·1 = 0 ✓, T1 = Q0 = 1 ✓.

A 4-bit down counter was reset to 0000 by mistake. What does it show after the first enabled edge?

0000 − 1 wraps to 1111 (15). So the very first step is a wrap-around (an underflow), which is usually not intended. Resetting to MAX gives a clean countdown: 15, 14, 13 …
