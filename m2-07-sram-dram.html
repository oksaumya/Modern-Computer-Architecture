SRAM vs DRAM: two ways to store a bit

SRAM stores each bit in a tiny latch made of 6 transistors: fast, but big and costly. DRAM stores each bit as charge on a tiny capacitor with 1 transistor: small and cheap, but slower, and it must be refreshed.

Think of it like this: SRAM is a light switch: flip it and it stays put for as long as the power is on. DRAM is a leaky bucket: full means 1, empty means 0, but the water slowly drips out, so someone must top up every bucket every few milliseconds.

Key terms

RAM
Random-access memory: any cell can be read or written directly by its address.
Transistor
An electronic switch. A control input (the gate) turns it on or off.
Capacitor
A tiny component that holds electric charge, like a small bucket for electrons.
Word line (WL)
A horizontal wire that selects one row of cells for reading or writing.
Bit line (BL)
A vertical wire that carries a bit into or out of the selected cell.
Sense amplifier
A circuit that detects a very small voltage change on a bit line and turns it into a clean 0 or 1.
Refresh
Reading every DRAM cell and writing its value back before its charge leaks away.
Density
How many bits fit in a given chip area. Higher density means cheaper per bit.

1. The core tension

The register file is very fast, but it holds only 32–128 words. At 20+ transistors per bit it can never scale to gigabytes.

Fast memory is small and expensive · big memory is slow and cheap"No single memory is fast, big, AND cheap. Computers cheat by layering them."

SRAM and DRAM are the two main ways to build large memories. They make opposite trade-offs:

SRAM stores ACTIVELY

Transistors keep pushing the bit back into place. Fast and stable, but bulky.

DRAM stores PASSIVELY

The bit is just charge sitting in a capacitor. Tiny and cheap, but it needs constant refreshing.

2. SRAM: static RAM

Each bit is a bistable latch: two inverters wired in a loop (see latches). "Static" means it needs no refresh while the power is on. It uses 6 transistors per bit (the "6T cell") and takes a few nanoseconds to access.

How it holds a bit

If Q = 1, the top inverter makes Q-bar (Q, the opposite of Q) = 0. Q = 0 goes into the bottom inverter, which drives Q back to 1. The loop keeps reinforcing itself, so any small leakage is corrected instantly. The bit is self-healing.

Read (non-destructive)

  1. Pre-charge both bit lines high.
  2. Raise WL (turn on M5, M6).
  3. The stored 0 side pulls its bit line slightly low.
  4. A sense amplifier sees which line dropped.

The latch keeps its value, so nothing needs to be rewritten.

Write

  1. Drive the bit lines to the new value (BL = bit, BL-bar = its opposite).
  2. Raise WL.
  3. The strong drivers overpower the cell.
  4. The latch flips and holds the new bit.

SRAM scorecard: very fast, no refresh, low density, expensive, and it draws some power all the time (static power). Used for the L1/L2/L3 caches.

3. DRAM: dynamic RAM

Each bit is charge on a capacitor: charged = 1, empty = 0. One access transistor connects it to the bit line. This is the 1T1C cell (1 transistor, 1 capacitor). Access takes about 50–100 ns.

Why DRAM must be refreshed

The capacitor is not perfect: its charge slowly leaks away. If it drops below the level the sense amplifier can recognise, a 1 turns into a 0 and the bit is lost. So the memory controller reads and rewrites every row about every 64 ms. While it refreshes, that memory is briefly unavailable. The class calls this "the single biggest practical difference".

Slide correction

The slide lists charge as "full at 0 ms, fading at 20 ms, weak at 50 ms, lost at 64 ms" and also says to refresh every ~64 ms. If data were really lost at 64 ms, refreshing at 64 ms would be too late. The correct idea: the refresh period (typically 64 ms) is chosen so that even the leakiest cell is rewritten before its charge falls below the sense threshold. Treat the slide numbers as a rough picture of the leak.

Reading DRAM destroys the bit

  1. 1. AccessWL rises; the capacitor shares its charge with the (much bigger) bit line
  2. 2. Tiny signalThe bit line moves only a very small amount
  3. 3. SenseThe sense amplifier swings it to a full 0 or 1
  4. 4. Write-backThat value is written back into the capacitor

Step 1 empties the capacitor, so the read is destructive. Every DRAM read is really a read + rewrite. Together with row activation and pre-charge, this makes DRAM access about 50–100 ns: more than 10× slower than SRAM.

DRAM scorecard: dense, cheap, slower, needs refresh. Used for main memory (8/16/32 GB).

Quick check

Which memory needs refresh? DRAM, because its capacitor leaks. SRAM's latch actively holds its value.

Where each is used

SRAM

  • CPU caches (on the chip, KB to MB)
  • Register files
  • Buffers

DRAM

  • Main memory (your "RAM sticks")
  • GPU frame buffers (GDDR)

5. Preview: the memory hierarchy

Computers stack memories in layers. Each step down is bigger, slower and cheaper per bit. The growing speed gap between the CPU and DRAM is called the memory wall. Module 5 covers this in depth: Memory wall & locality.

Common mistakes & exam traps

Slips that cost marks
  • "SRAM needs refresh" is false. Only DRAM does. SRAM keeps its data as long as it has power.
  • "Static" does not mean non-volatile. SRAM still loses everything when the power goes off.
  • Mixing up the cells: SRAM = 6 transistors; DRAM = 1 transistor + 1 capacitor.
  • Forgetting write-back: a DRAM read destroys the stored charge, so it must be rewritten.
  • Wrong uses: caches are SRAM; main memory is DRAM. Not the other way round.
  • "DRAM is ~6× denser" comes from 1 capacitor vs 6 transistors per bit.

Practice

How many transistors are in one SRAM cell and one DRAM cell?

SRAM: 6 (6T). DRAM: 1, plus one capacitor (1T1C).

Why does DRAM need refresh but SRAM does not?

DRAM stores the bit as charge on a capacitor, which leaks. SRAM stores it in two cross-coupled inverters that keep driving each other, so the value corrects itself.

What does "destructive read" mean, and how does DRAM deal with it?

Reading shares the capacitor's charge with the bit line, which wipes out the stored value. The sense amplifier recovers the bit, then the controller writes it back into the cell.

List the four steps of an SRAM read.

1. Pre-charge both bit lines high. 2. Raise the word line. 3. The cell pulls one bit line low. 4. The sense amplifier detects which line dropped.

Which memory would you use for an L1 cache, and why?

SRAM. The L1 cache must answer in a few ns, and it is small (KB), so SRAM's high cost per bit is affordable.

A 1 GB memory made of 6T SRAM vs 1T1C DRAM: roughly how many transistors each?

1 GB ≈ 8 × 10⁹ bits (using 1 GB = 10⁹ bytes).
SRAM: 6 × 8×10⁹ = 48 billion transistors.
DRAM: 8 billion transistors + 8 billion capacitors. That is why main memory is DRAM.

Name the layers of the memory hierarchy from fastest to slowest.

Registers → cache (SRAM) → main memory (DRAM) → SSD/disk.
