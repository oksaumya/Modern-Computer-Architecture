AMAT & multi-level caches

AMAT (Average Memory Access Time) is one number that tells you how fast a memory hierarchy is on average. You always pay the cache's own time. On a miss, you also pay the time of the next level. Adding a second cache level makes misses much cheaper.

Think of it like this: you always check your pocket for your keys (1 second). One time in ten they aren't there, so you check your bag (10 seconds). One time in five they aren't in the bag either, so you search the house (100 seconds). Your average search is 1 + 0.1 × (10 + 0.2 × 100) = 4 seconds. Without the bag it would be 1 + 0.1 × 100 = 11 seconds.

Key terms

Hit time
Time to check a level and get the data when it is there. Paid on every access to that level.
Miss rate (MR)
Fraction of accesses to a level that miss. 5% = 0.05.
Miss penalty
Extra time a miss costs: the time spent in the slower levels below.
Local miss rate
Misses at a level ÷ accesses that reached that level.
Global miss rate
Misses at a level ÷ all accesses made by the CPU.
CPI
Average clock cycles per instruction. See Performance.
Memory stall cycles
Clock cycles the CPU spends waiting for memory after misses.

1. The AMAT formula (one level)

AMAT = hit time + miss rate × miss penaltyYou always pay the hit time. A fraction "miss rate" of the time you also pay the penalty.

Example 1

  1. Cache hit time = 1 ns, miss rate = 5%, miss penalty = 20 ns.
  2. AMAT = 1 + 0.05 × 20 = 1 + 1 = 2 ns.
  3. Even a 5% miss rate doubles the average time compared with a perfect cache (1 ns).

  2. 2. Start at the bottommain memory always "hits"
  3. 3. Work upwardspenalty of a level = AMAT of the level below

2. Multi-level caches

With two cache levels, a miss in L1 does not go straight to DRAM. It goes to L2 first. So the miss penalty of L1 is the AMAT of L2.

AMAT = TL1 + MRL1 × ( TL2 + MRL2 × Tmem )MRL2 here is the local miss rate of L2. The bracket is L1's miss penalty.

Example 2

  1. L1: 1 ns, miss rate 10%. L2: 10 ns, local miss rate 20%. Main memory: 100 ns.
  2. L1's miss penalty = L2's AMAT = 10 + 0.2 × 100 = 10 + 20 = 30 ns.
  3. AMAT = 1 + 0.1 × 30 = 1 + 3 = 4 ns.
  4. Without L2: AMAT = 1 + 0.1 × 100 = 1 + 10 = 11 ns. L2 makes memory access almost 3× faster (11 ÷ 4 = 2.75).

3. Local vs global miss rate

Local miss rate of L2

L2 misses ÷ L2 accesses

L2 only sees the "hard" accesses that L1 already missed, so its local miss rate often looks high (20% here, sometimes 50%+).

Global miss rate of L2

L2 misses ÷ all CPU accesses
= MRL1 × MRL2, local

Example 2: 0.1 × 0.2 = 0.02 = 2%. Only 2% of all accesses reach DRAM.

AMAT = TL1 + MRL1 × TL2 + (global MRL2) × TmemThe same formula with the bracket multiplied out: 1 + 0.1 × 10 + 0.02 × 100 = 4 ns ✓
Which one to quote?

A high local miss rate for L2 is not a sign of a bad L2. Judge the whole system by the global miss rate (how often the CPU reaches DRAM) or, best, by the AMAT itself.

The formula as a tiny program

python · amat.pycode → what it means
def amat(levels, t_mem):A function. levels is a list of (time, local miss rate) pairs from L1 downward; t_mem is the main-memory time.
total = t_memStart at the bottom: main memory always hits.
for t, mr in reversed(levels):Walk upwards: last cache level first, L1 last.
total = t + mr * totalThis level's AMAT = its time + miss rate × (AMAT of everything below).
return totalAfter the loop, total is the AMAT seen by the CPU.

4. From AMAT to CPI

Misses slow down whole programs. Measure the damage as extra clock cycles per instruction:

CPI = base CPI + memory stall cycles per instructionstall cycles per instruction = misses per instruction × miss penalty (in cycles)
misses per instruction = miss rate × memory accesses per instructionEvery instruction is fetched (1 access); loads and stores add a data access.

Example 3: adding an L2 cache

Base CPI = 1.0 (if every access hit). L1 miss rate = 2% per instruction. Going to main memory costs 100 cycles. An added L2 costs 25 cycles to check, and the global miss rate (reaching main memory) drops to 0.5%.

  1. L1 only: CPI = 1 + 0.02 × 100 = 1 + 2 = 3.0.
  2. With L2: every L1 miss pays 25 cycles, and 0.5% of instructions also pay 100 cycles.
    CPI = 1 + 0.02 × 25 + 0.005 × 100 = 1 + 0.5 + 0.5 = 2.0.
  3. Speedup = 3.0 ÷ 2.0 = 1.5×.

Numbers are simplified from the Patterson & Hennessy example (which works in 0.25 ns clock cycles: 400-cycle and 20-cycle penalties, CPI 9.0 → 3.4, speedup ≈ 2.6). The method is identical.

Example 4: instruction and data misses

Patterson & Hennessy: base CPI = 2, instruction miss rate = 2%, data miss rate = 4%, miss penalty = 100 cycles, and 36% of instructions are loads or stores (so they make a data access).

  1. Instruction stalls = 1 × 0.02 × 100 = 2.00 cycles per instruction (every instruction is fetched).
  2. Data stalls = 0.36 × 0.04 × 100 = 1.44 cycles per instruction (only 36% touch data).
  3. CPI = 2 + 2.00 + 1.44 = 5.44. A perfect cache would give CPI 2, so the real cache makes the CPU 5.44 ÷ 2 = 2.72× slower.

Common mistakes & exam traps

Slips that cost marks
  • Writing AMAT = MR × penalty and forgetting the hit time. You always pay the hit time.
  • Writing AMAT = (1 − MR) × hit + MR × penalty. That is only right if "penalty" already includes the time spent checking the cache. Use the standard form unless the question says otherwise.
  • Multiplying by the global L2 miss rate inside the bracket. The nested formula uses the local rate.
  • Percent vs decimal: 5% is 0.05, not 5.
  • Mixing ns and clock cycles in one sum. Convert first.
  • Forgetting that only a fraction of instructions (loads/stores) make data accesses.

Practice

Hit time 0.5 ns, miss rate 2%, miss penalty 100 ns. Find the AMAT.

0.5 + 0.02 × 100 = 0.5 + 2 = 2.5 ns.

Hit time 1 ns, miss penalty 20 ns. What miss rate gives an AMAT of 1.5 ns?

1.5 = 1 + MR × 20 → MR = 0.5 ÷ 20 = 0.025 = 2.5%.

Cache A: 1 ns, MR 5%. Cache B: 1.5 ns, MR 2%. Penalty 50 ns. Which is faster on average?

A: 1 + 0.05 × 50 = 3.5 ns. B: 1.5 + 0.02 × 50 = 2.5 ns. B wins, even though its hit time is slower.

Three levels: L1 1 ns (MR 5%), L2 5 ns (local MR 30%), L3 20 ns (local MR 20%), memory 100 ns. Find AMAT and the global miss rates.

From the bottom: L3 = 20 + 0.2 × 100 = 40. L2 = 5 + 0.3 × 40 = 17. L1: AMAT = 1 + 0.05 × 17 = 1.85 ns.

Global MR: L2 = 0.05 × 0.3 = 1.5%; L3 = 0.05 × 0.3 × 0.2 = 0.3%.

1,000 memory references: L1 misses 40 times, L2 misses 20 times. Find L1's miss rate, and L2's local and global miss rates. Then find AMAT if L1 = 1 cycle, L2 = 10 cycles, memory = 200 cycles.

L1 MR = 40 / 1000 = 4%. L2 local = 20 / 40 = 50%. L2 global = 20 / 1000 = 2%.

AMAT = 1 + 0.04 × (10 + 0.5 × 200) = 1 + 0.04 × 110 = 5.4 cycles.

Base CPI 1.5. Each instruction makes 1.3 memory accesses on average. Miss rate 3%, penalty 60 cycles. Find the CPI.

Stalls = 1.3 × 0.03 × 60 = 2.34. CPI = 1.5 + 2.34 = 3.84.

L2 has a local miss rate of 50%. Is L2 useless?

No. L2 only sees the accesses that L1 missed. If L1's miss rate is 4%, the global rate is only 2%, and L2 still halves the trips to slow DRAM.
